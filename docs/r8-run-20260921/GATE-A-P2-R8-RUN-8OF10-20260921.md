## What was actually wrong
Every blocker found was in the harness or in observation plumbing. **No product
predicate ever failed.** The defects were stacked, each hiding the next:

1. **STABLE_AFTER written after the judge ran** — six runner generations
   (`5a782f6` through `b984ded-v3`) wrote `stable-after.json` during CLEANUP, after
   `judge_c1`'s `check_stable()` had already read it. Every cell was therefore
   deterministically `R8_INVALID STABLE_EVIDENCE_MISSING`. `65938a4` had the order
   right. attempt-09 was simply the first run clean enough to reach the judge at all.
2. **judge/fixture contract drift** — `judge_c1` required observation phases that
   `cell_c1` structurally cannot emit (they need a REGISTER_BUFFER, which is C4's
   cell). `judge_c5_overflow` required a checkpoint its fixture never sent. A new
   standing gate, `V2-P009`, now detects this class statically before any grant.
3. **product: duplicate `phase` key** — `ProcLorieR8Checkpoint` appends
   `"phase":<n>` after the envelope's `"phase":"X_CHECKPOINT"`, so a standard JSON
   parse overwrites the observation kind and the rows become unfindable. Contained
   in the collector (first key wins); product not rebuilt.
4. **product: `total_actual_buffer_pending` hardcoded null** — the field judge_c1
   asserted on is never populated. Residue is now proven from fields the product
   does populate. Also contained tooling-side.
5. **judge_c3 implemented one of two legal traces** — presentproto says a window
   destroyed before presentation never completes, and §7.3 says so explicitly, but
   the judge required `PRESENT_POST_ACK` unconditionally. The cancellation path is
   now accepted, but only when *proven* (destination released, no fatal).
6. **two `put_image` buffer defects** — `cell_c5_full` declared 16 KiB of image data
   and passed a 4-byte local (overread, killed the X connection);
   `cell_c5_overflow` had the inverted defect. `cell_d` waited for eight Present
   events that were never selected and hung until the 20 s timeout.

## Method note
After the second consumed attempt, every judge or fixture change was **replayed
offline against already-captured evidence before spending another attempt**, and
previously passing cells were re-judged to prove no regression. That is how items
3-5 above were found and fixed without additional device runs.
