## 架構重點

- 一個治理模組 `f8_hybrid2_budget.py`，四個模式只差 `PROFILES` 一列：relay 租約數（= daemon session 數）、**全組執行槽**（daemon 原生 worker 與 relay 本地／fallback worker 共用，跨 PRoot／原生以 flock 計數）、每 session 佇列 4。連線數與執行數分開管理。

## 剩餘限制

- 全部是**合作式配額**：同一預算目錄與環境變數的程序才受限。非 root Android 無 cgroup；`RLIMIT_*` 為每程序且會被 git 繼承，未採用；`/proc/pressure` 讀取被拒。
- git 子程序記憶體、`os.walk` 單目錄列舉大小沒有程式上限，只有實測。
- 6 路理論只餘 0.7 MiB；閒置 PSS 多 1 MiB 就會翻成 HOLD。日用以 4 路為準。
- 慢讀者最多佔一個執行槽 30 秒（預設逾時）後才關 session。daemon 與 relay 本地等待者之間的跨程序公平不是 FIFO。
- 原生 3.14 與 PRoot 3.12 在約 10,000–15,600 層巢狀 JSON 上結果不同（前者可解析）。
- 回退：不設 `F8_HYBRID2_BUDGET_DIR` 即回到原 7.4 行為；`F8_NO_HYBRID=1` 全走 PRoot。本輪未部署任何東西。
