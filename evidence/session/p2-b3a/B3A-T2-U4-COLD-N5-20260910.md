本身較慢。

## Resource / lifecycle endpoints

- 十個 independent X server 都從 telemetry `x_fd_start=79` 開始，在 CloseScreen snapshot
  為 `x_fd_end=89`；每次 process teardown 後 `NO_X3_RESIDUE`。因此未觀察到
  cross-recreate FD retention。
- actual X PID 的 external RSS T0/T1/T2/T3 在每 session `resources.txt` 保存。
- adb shell 對 live `/proc/<PID>/fd` directory 不可讀，故外部 FD count 是
  `NOT OBSERVABLE`，不把空結果寫為 0。
- renderer RSS/FD metadata 皆 0，表示 current schema 沒有 renderer-side attribution；
  不得解釋成 renderer 使用 0 resource。
