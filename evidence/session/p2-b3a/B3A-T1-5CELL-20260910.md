# B3a Tier-1 五格成本普查 — 2026-09-10（第一輪，用戶指定範圍）

範圍（只做這五格，不擴散）：1x1、5x24、32x32、64x64、256x256。
每格：warmup 100＋measured 500，warm reuse、immediate GetImage（mode=1）、batch=1、cold=0。
候選：CPU（`DISABLE_EXA_GPU=1`，fallback 全 1）vs R3（fallback 全 0）。
方法：holder＋oracle 閘門＋批量 cells＋holder 釋放 dump，每 session 單一 X 實例；
`next_record == expected` 才接受（4519＝oracle 1519＋5×600）。

候選版本：實驗版 `1.03.01-1954f82`（telemetry 修復版）；Stable `:1` 全程未碰。
Target：內建 displayId=0；HDMI 保持非 target，未切換顯示模式。
